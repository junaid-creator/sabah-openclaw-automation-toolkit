# Deployment checklist

- [ ] New isolated host/account; no production configuration copied wholesale.
- [ ] Commit recorded; requirements installed in venv; pip check and all tests pass.
- [ ] Scaffold dry run inspected, explicit apply targets a new private directory.
- [ ] Main and customer-support workspaces separate; models/auth configured individually.
- [ ] Customer sandbox verified against cross-workspace file reads and unauthorized tools.
- [ ] Owner account/peer route verified; unknown senders and groups rejected.
- [ ] Test contacts only; no production customer channel enabled.
- [ ] Original skills selected individually; unresolved derivative packages excluded.
- [ ] Secrets stored outside checkout/model context; assets redistribution rights verified.
- [ ] Read-only provider checks pass against authorized accounts.
- [ ] Exact-content confirmation, revocation and restart/no-replay tested.
- [ ] Timeout after remote success reconciled without a second POST/send.
- [ ] Semantic support policy and language behavior independently evaluated.
- [ ] Actual channel message receipts verified; generated text is not delivery.
- [ ] Off-host private-state backup and isolated restoration tested.
- [ ] Fresh-install end-to-end evidence retained per feature; partial features remain labeled.
- [ ] Only separately approved schedules enabled; one scheduler per workflow.

All boxes are operator acceptance tasks, not assertions that this release completed them.

## Expanded preproduction gates

- [ ] Validate each website independently; customer/group/cross-site commands fail.
- [ ] Prove native product hook metadata, real exact preview and confirmation on a
      disposable installation; library callbacks are not live delivery proof.
- [ ] Test in-flight revocation, no-replay reconciliation and separately approved
      scoped restore before permitting real product changes.
- [ ] Prove database restore, storefront/variation/cart behavior beyond REST readback.
- [ ] Review all photo/logo/font/voice/model rights and dependencies.
- [ ] Validate actual local speech quality and native audio/text priority.
- [ ] Verify isolated monitor service cadence and explicitly authorized owner TEST.
- [ ] Prove encrypted off-host recovery, not merely same-disk restore-copy hashes.

No unchecked live gate is satisfied merely by installing the toolkit.
