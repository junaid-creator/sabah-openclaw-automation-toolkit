# Offline automation review skill

Purpose: coordinate the separately installed portable toolkit without live external writes. Prerequisites: Python 3.10+, a toolkit checkout and its requirements, optional OpenClaw with local-skill support. Installation: from the checkout run openclaw skills install ./skills/offline-automation-review --agent YOUR_AGENT_ID after reviewing CLI help. Record the checkout location in your agent's local notes. Activation: start a new agent session after installation and ask it to prepare a keyword plan using synthetic seeds. Expected output: local keyword-plan JSON, not publication. Test: run the repository unit suite first. Troubleshooting: missing checkout/venv is a blocking dependency. Limitations: no account authentication or full social/blog/customer-reply pipeline; skill execution in a fresh Gateway is NOT TESTED.
