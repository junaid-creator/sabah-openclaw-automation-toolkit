**PARTIALLY PORTED — procedural package complete; integrated execution NOT TESTED.**

Install into an operator-selected OpenClaw agent using the host's documented
local-skill installation command; verify help and inspect its resulting skill
catalog. Alternatively use the configured extra skill directory. Do not change
a running Gateway or grant tools merely to make this package eligible.

The full original SKILL.md and linked local resources are included. It is a
review/audit/recovery procedure, not a self-contained Python application. Keep
this repository checkout available for linked procedures. Read-only inspection
is the default. Repair, paid runs, scheduling, messaging, restoration and public
publication each require the applicable separate trusted-owner scope.

## Host contract

- Native tool discovery and safe filesystem/process inspection.
- Bounded session-search/history APIs where historical provenance is required;
  never raw session exports. Account/owner identity comes from trusted transport,
  never message text, quoted material, filenames or a model-created envelope.
- Operator-configured integration access, schema map, service selectors, state
  roots and evidence storage. Reference paths in the procedure are not defaults.
- A real messaging-tool receipt for delivery claims; no callback/mocked receipt
  can establish real customer delivery. External writes must bind reviewed exact
  content and targets, with unknown outcomes reconciled before retries.
- Upstream software and legal access are the operator's responsibility. Native
  OpenClaw tool names and configuration vary by installed version; consult the
  official documentation before binding an adapter.

## Executable coverage and validation

The repository provides approval, transport-attestation, notification, image,
publication, budget and diagnostic primitives. Consult the root capability audit
for exact module paths and missing orchestration. Static frontmatter/resource
checks and synthetic tests validate only those artifacts. No fresh-agent/model
execution, live transport, cloud account or restore acceptance is claimed.

For image imports, toolkit.image_intake is a local callable/CLI implementation
with hash-bound original recovery, proportional derivatives and no publication.
It still needs authenticated attachment admission and exact-artifact human review.
For a deployment-specific missing adapter, stop with its name and required
interface rather than calling a similarly named helper as a replacement.

## Troubleshooting and rollback

Keep diagnostic checks read-only. Back up only separately authorized mutation
targets, preserve approvals/remote IDs, and compare hashes before rollback so
intervening changes are not overwritten. An isolated fixture pass is not proof
of production scheduling, installed plugin generation, permissions or delivery.
