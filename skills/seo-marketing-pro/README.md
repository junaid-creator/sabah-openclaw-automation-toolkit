# SEO planning skill

The eight-phase original procedure and checklist are included. Helpers require
the toolkit checkout: from its root use PYTHONPATH=. python
skills/seo-marketing-pro/scripts/SCRIPT.py --help or python -m toolkit.MODULE.
Modules: keyword_research, content_brief_generator, local_metadata, elementor_plan.
Local metadata edits are not WordPress writes; dry-run remains the default.

The Elementor helper only prints a plan, regardless of --dry-run. It does not
execute commands or install agent-browser. Never blindly execute a generated
plan: inspect current UI through an authorized native browser and separately
approve sensitive writes. External services are upstream dependencies.
Keyword expansion is heuristic, not measured search volume. Analytics, outreach,
email, social sends and live Elementor execution are NOT TESTED. Skill install
requires the documented operator-selected OpenClaw agent and tool permissions.
