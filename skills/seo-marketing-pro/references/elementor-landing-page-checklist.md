# Elementor Landing Page Checklist

## Before opening Elementor AI

- Define the single conversion goal.
- Define the audience and offer.
- Define the target keyword and page intent.
- Gather proof points, FAQ items, and CTA text.

## Build order

1. Hero with one clear headline and CTA
2. Benefits or outcomes section
3. Proof section with testimonials, stats, or logos
4. Objection handling section
5. CTA block
6. FAQ section

## Review checklist

- Headline matches search and ad intent
- CTA appears above the fold and near the bottom
- Mobile spacing is clean
- Form fields are minimal
- Trust elements are visible
- Metadata is set
- Images have alt text
- Internal links are intentional
- Thank-you flow is defined

## After generation

- Rewrite generic AI copy
- Tighten claims and remove filler
- Add business-specific trust language
- Check title tag and meta description
- Preview mobile before publish
