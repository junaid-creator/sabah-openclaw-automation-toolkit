# Prerequisites

Python 3.11 or newer, venv/pip and a writable isolated directory. Linux/POSIX is required for fcntl locks and directory fsync. requests is used by knowledge snapshots; other runtime modules use the standard library. Tests use unittest and synthetic fixtures.

OpenClaw 2026.9.8 documentation informed the optional skill instructions. The package does not pin, install or modify OpenClaw. Other versions, Windows and fresh VPS end-to-end installation are NOT TESTED. Do not use root to run this toolkit.
