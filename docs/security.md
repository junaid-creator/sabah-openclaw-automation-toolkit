# Security review boundaries

See SECURITY.md. Only allowlisted source-derived files enter the candidate. No live state directory, credentials, media, customer records, agent memory or prior Git history is copied. Production source hashes are checked separately and never used to imply that every active service state is frozen.

The local author/source review uses owner authorization, local source location, source hashes and inspection for third-party notices. It is not independent legal provenance verification. Unresolved derivative procedural skills and bundled/plugin implementations are not relicensed. MIT applies only to included original adaptations and newly authored packaging. Third-party runtime dependencies retain their own licenses; no dependency source is vendored. Source data from OSM/Overture has separate data licensing obligations; no real data is included.
