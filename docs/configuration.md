# Configuration

The offline commands need no secrets. Optional TOOLKIT_STATE_DIR selects the local directory for reliability runs and the content ledger; the default is the user's local state directory. The library does not load .env automatically: export reviewed variables in your shell or use your own secure environment loader. Do not source untrusted .env files.

Lead qualification takes an explicit JSON profile with a bounding box and industry keywords. The built-in Overture heuristics target construction/maintenance; changing the profile does not generalize every hardcoded category filter. Currency is an explicit knowledge-snapshot argument and must match the source; the module does not validate or convert currencies.

For future service adapters, use your own scoped credentials in a secret manager. WordPress write access, Google OAuth scopes, Meta/TikTok posting grants and WhatsApp/Telegram routing are intentionally NOT configured here. Never reuse another organization's identifiers or credentials. See upstream references for current provider setup.
