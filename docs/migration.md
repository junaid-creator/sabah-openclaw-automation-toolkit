# Migration

Do not copy an existing OpenClaw state directory. Install into a fresh isolated checkout, use synthetic fixtures, choose your own state directory and configure your own services separately. The production tool filenames in provenance are attribution labels, not paths to execute.

Language defaults remain English. Ledger duplicate detection is normalization-based, not semantic deduplication. Knowledge snapshots are reference material, not customer-response authority. Existing production ledgers and approval receipts cannot be imported as authorization for this toolkit. Live publishing/recovery engines are not compatible replacements because they are not included.
