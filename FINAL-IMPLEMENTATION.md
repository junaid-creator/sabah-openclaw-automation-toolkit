## Fresh isolated install

Use Linux/POSIX, Python >=3.12 and Node 24 for the full acceptance runner. No live provider credentials are inherited. Run from a fresh checkout:

```sh
python3 tests/fresh_install.py --environment /absolute/new-private-environment --report /absolute/private-report.json --render-dependencies
```

This creates a new venv, installs exact pins, checks dependencies, runs all Python/Node tests, validates native social syntax and executes the source release gate. It never activates plugins, services, schedules or accounts. Installation fetches public packages, not paid APIs. Optional real Chromium acceptance requires separately installed upstream Chromium and licensed local fonts:

```sh
python tests/browser_fixture_acceptance.py --output /absolute/new-browser-evidence

python tests/social_render_acceptance.py --config /absolute/new-render-evidence/example-private.json --output /absolute/new-social-evidence
```

## Recovery and rollback

Install only on a separate authorized target; retain the public commit/tree and private config/ledger backup. Roll back code by selecting a prior reviewed release, not by deleting receipts or restoring whole private runtime directories. Disable only newly installed target adapters before rollback. Unknown remote outcomes remain fenced; reconcile existing IDs read-only, never recreate jobs to bypass a latch. Revocation cannot undo an already admitted remote request. Never import production approvals into a new deployment.
