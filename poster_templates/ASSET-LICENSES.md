# Asset and font boundaries

The three CSS files and renderer structures are adaptations of the owner's original
reference/catalog/co-brand implementations. Source paths/hashes are in PROVENANCE.
No original production logo, QR/contact artwork, photography or font file is copied.

The four SVG files in assets/ were created for this toolkit and are covered by its
MIT license. They are visibly synthetic DEMO placeholders, not commercial branding.
qr-placeholder.svg is deliberately NOT a valid QR code. Replace it with an owned
asset and independently decode the exported final image before production use.

Fonts are supplied by the operator. Local tests used installed DejaVu Sans; that
font is not redistributed. Verify your chosen font's license, language coverage,
weight/metrics and render fit. Render results with substitutes are not an exact
pixel recreation of the production brand. Platform icon code retains the original
hand-authored SVG paths; no external icon library is bundled.

Photos/atlases are runtime inputs. The test atlas is generated synthetically by
the local acceptance fixture; no source/customer photo is included or uploaded.
