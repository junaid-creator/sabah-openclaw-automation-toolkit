## Quick start

Use Linux/POSIX and **Python 3.12+** for the full pinned dependency set and fresh
acceptance runner; **Node 24** is required for native SQLite tests.

```sh
git clone https://github.com/junaid-creator/sabah-openclaw-automation-toolkit.git
cd sabah-openclaw-automation-toolkit
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
node --test tests/test_*.mjs
python tests/release_gate.py
```

Fresh isolated reproduction with individual stdout/stderr/exit/timeout evidence:

```sh
python3 tests/fresh_install.py --environment /absolute/new-private-environment --report /absolute/private-report.json --render-dependencies
```

The runner installs public pinned packages without inheriting provider credentials
or activating services/schedules/channels/plugins. Actual render acceptance needs
separately installed compatible Chromium and operator-licensed fonts.
`tests/social_render_acceptance.py` accepts `--chromium /absolute/path/to/chrome`;
a new HOME does not implicitly contain Playwright browser binaries.

Offline examples:

```sh
mkdir -p output
python -m toolkit.keyword_research --input examples/seeds.txt --output output/keywords.json
python -m toolkit.content_brief_generator --input output/keywords.json --output output/briefs.json
python -m toolkit.knowledge_snapshot --base-url https://example.com --currency USD --fixture examples/site-fixture.json --output output/knowledge
```

## Native runtime and safety

A separate OpenClaw **2026.11.5** installation was reused: configuration, exact
24 main skills / zero support leakage, actual boot/health with OS-denied external
network, disabled schedules and denied tools passed. Teardown was explicit.
Native SDK import/registration fixtures are separate from real chat admission.
The previously linked owner plugins remain disabled; discovery is not activation.

- Creation is draft-only; exact reviewed approval is separate from publishing.
- Unknown outcomes stay fenced; failed reporting never authorizes republishing.
- Keep state/evidence outside Git. No credentials, customer records, private Git
  history, production branding or voice models are redistributed.
- Synthetic QR/branding fixtures are not production-ready. Leads are prospects,
  not confirmed buyers, and authorize no outreach.
- Network/writes require explicit configuration/opt-in. Never take privileged
  routes or destinations from untrusted customer text.
- Native OpenClaw npm findings are recorded separately from toolkit dependencies.
  No production update or automatic repair is authorized by installation.

Remaining engineering includes native worker/scheduler and full Sheet wiring,
model/image/semantic-result adapters, geography-specific enrichment, voice
integration, target stop-policy binding and procedure-specific host bindings.
These are **not** labeled credentials-only blockers. See the
[specific unfinished list](docs/recovery-release.md).
